1. EXECUTIVE SUMMARY & PARADIGM SHIFT

1.1 The Failure of Legacy Reconnaissance Architecture

First-generation hazard scouting prototypes (including legacy systems relying on basic MQ-series analog gas sensors) suffered from a fundamental flaw: Statistical Ambiguity. Standard metal-oxide gas sensors (MQ-2, MQ-135) operate with broad cross-sensitivity. An analog voltage spike across an MQ sensor can be triggered by target precursor chemicals ($NH_3$, $NO_x$), but it can equally be triggered by ambient humidity, alcohol vapors, elevated temperatures, or engine exhaust.

When software algorithms average these noisy analog signals into a percentage score (e.g., "70% Hazard Risk"), they output a statistical probability. For explosive ordnance disposal (EOD), bomb disposal technicians, and hazmat first responders, a statistical probability is operationally useless—it fails to confirm whether a physical threat truly exists or if the sensor is experiencing environmental drift.

2.1 Gas Spectroscopy: MOx MEMS Sensors (Sensirion SGP41 & DFRobot Fermion $NH_3$)

Gas-Solid Interface Chemistry & Chemisorption

Both the Sensirion SGP41 (VOC/$NO_x$) and the DFRobot Fermion $NH_3$ sensor utilize Metal-Oxide Semiconductor (MOx) MEMS technology with nanocrystalline Tin Dioxide ($\text{SnO}_2$) thin films deposited over an integrated micro-hotplate.

When the sensor operates in clean ambient air, the micro-hotplate heats the $\text{SnO}_2$ layer to approximately $300^\circ\text{C}-400^\circ\text{C}$. At this elevated temperature, atmospheric oxygen molecules ($\text{O}_2$) adsorb onto the semiconductor surface. The electronegative oxygen extracts free electrons from the conduction band of the n-type $\text{SnO}_2$ material, trapping them at the surface as negative ions ($\text{O}^-$ or $\text{O}_2^-$):

$$\text{O}_2 \text{ (gas)} + 2e^- \longrightarrow 2\text{O}^- \text{ (adsorbed)}$$

This electron extraction forms a high-resistance energy barrier known as an Electron Depletion Layer ($W_D$) beneath the semiconductor surface, restricting current flow.

Reducing Target Reaction ($NH_3$)

When Ammonia gas ($NH_3$), a primary precursor for nitrate-based improvised explosives, comes into contact with the heated sensor surface, it undergoes an oxidation-reduction reaction with the trapped oxygen ions:

$$2\text{NH}_3 + 3\text{O}^- \text{ (adsorbed)} \longrightarrow \text{N}_2 + 3\text{H}_2\text{O} + 3e^-$$

This reaction releases the trapped electrons back into the $\text{SnO}_2$ conduction band, rapidly shrinking the depletion layer $W_D$ and causing an exponential drop in electrical resistance ($R_s$). The relationship between gas concentration ($C$) and sensor resistance is governed by the empirical power-law equation:

$$R_s = A \cdot [C]^{-\alpha}$$

Where $A$ is a material constant and $\alpha$ is the sensitivity slope. The DFRobot Fermion sensor conditions this resistance change into an onboard analog voltage output calibrated specifically for $1-300\text{ ppm}$ of $NH_3$.

2.2 Inductive Metal Detection: LJ12A3 NPN Sensor

The LJ12A3-4-Z/BX sensor detects concealed metallic shrapnel, battery enclosures, and switching hardware through High-Frequency Electromagnetic Induction and Eddy Current Loss.

Eddy Current Generation (Faraday's & Lenz's Laws)

When a conductive metallic target enters the sensor's alternating magnetic field ($\mathbf{B}_{\text{sensor}}$ operating at $100\text{ kHz}-1\text{ MHz}$), the time-varying magnetic flux ($\Phi_B$) induces an electromotive force ($\mathcal{E}$) within the metal target according to Faraday's Law of Induction:

$$\mathcal{E} = -\frac{d\Phi_B}{dt}$$

This induced voltage causes free electrons within the target metal to circulate in closed loops known as Eddy Currents. According to Lenz's Law, these eddy currents generate their own opposing magnetic field ($\mathbf{B}_{\text{eddy}}$) that resists the original sensor field, sapping oscillator energy and triggering an internal Schmitt trigger to pull the signal line to Ground ($0\text{V}$).

2.3 Non-Contact Thermal Sensing: MLX90614 Thermopile

All matter at temperatures above absolute zero emits electromagnetic radiation in the infrared spectrum. The total radiant energy ($P$) emitted per unit surface area is defined by the Stefan-Boltzmann Law:

$$P = \varepsilon \cdot \sigma \cdot A \cdot (T^4 - T_0^4)$$

Infrared photons pass through a silicon lens and strike a micromachined thermopile membrane, heating "hot junctions" relative to "cold junctions" anchored to the substrate, generating a thermoelectric voltage via the Seebeck Effect that is converted into a digital temperature over $I^2C$.

4.1 Battery Divider Math ($100\text{ k}\Omega$ and $27\text{ k}\Omega$)

The resistor voltage divider scales raw LiPo voltage ($11.1\text{V}-12.6\text{V}$) to a range safe for the ESP32's 12-bit ADC:

$$V_{\text{ADC}} = V_{\text{Battery}} \times \left( \frac{R_2}{R_1 + R_2} \right) = V_{\text{Battery}} \times \left( \frac{27\text{ k}\Omega}{100\text{ k}\Omega + 27\text{ k}\Omega} \right) \approx V_{\text{Battery}} \times 0.2126$$

At full battery charge ($12.6\text{V}$), $V_{\text{ADC, MAX}} = 12.6\text{V} \times 0.2126 = 2.678\text{V}$, well within the $3.3\text{V}$ input threshold.

5.2 Embedded Implementation Code

#include <Arduino.h>
#include <WiFi.h>
#include <esp_now.h>
#include <Wire.h>

#define PIN_BATTERY_ADC  1
#define PIN_LED_RED      2
#define PIN_LED_GREEN    3
#define PIN_NH3_ADC      4
#define PIN_METAL_SENS   6
#define PIN_BUZZER       7
#define PIN_I2C_SDA      8
#define PIN_I2C_SCL      9

typedef struct __attribute__((packed)) {
  uint8_t threat_stage;    // 0: Clean, 1: Vapor, 2: Metal, 3: Verified Match
  float battery_voltage;   // Calculated pack voltage
  float nh3_ppm;           // Ammonia concentration
  bool metal_present;      // Inductive trigger state
} TelemetryPacket;

TelemetryPacket txData;
TaskHandle_t SensorProcessingTask;

// CORE 1: REAL-TIME 100Hz SENSOR SWEEP & COINCIDENCE MATRIX
void SensorTaskCode(void * pvParameters) {
  TickType_t xLastWakeTime = xTaskGetTickCount();
  const TickType_t xFrequency = pdMS_TO_TICKS(10); // 10ms (100Hz)

  for (;;) {
    // 1. Read Battery Voltage
    float rawBatADC = analogRead(PIN_BATTERY_ADC);
    txData.battery_voltage = ((rawBatADC / 4095.0) * 3.3) / 0.2126;

    // 2. Read Chemical Sensors
    float rawNH3ADC = analogRead(PIN_NH3_ADC);
    txData.nh3_ppm = (rawNH3ADC / 4095.0) * 300.0;
    bool chemAnomaly = (txData.nh3_ppm > 50.0);

    // 3. Read Metal Sensor (Active Low)
    txData.metal_present = (digitalRead(PIN_METAL_SENS) == LOW);

    // 4. Deterministic Coincidence Evaluation
    if (chemAnomaly && txData.metal_present) {
      txData.threat_stage = 3; // MULTI-VECTOR VERIFIED THREAT
    } else if (txData.metal_present) {
      txData.threat_stage = 2; // CASING CONFIRMED ONLY
    } else if (chemAnomaly) {
      txData.threat_stage = 1; // VAPOR ANOMALY ONLY
    } else {
      txData.threat_stage = 0; // SYSTEM CLEAR
    }

    // 5. Actuate Hardware Indicators
    digitalWrite(PIN_LED_RED, (txData.threat_stage > 0) ? HIGH : LOW);
    digitalWrite(PIN_LED_GREEN, (txData.threat_stage == 0) ? HIGH : LOW);
    digitalWrite(PIN_BUZZER, (txData.threat_stage == 3) ? HIGH : LOW);

    vTaskDelayUntil(&xLastWakeTime, xFrequency);
  }
}

void setup() {
  pinMode(PIN_METAL_SENS, INPUT_PULLUP);
  pinMode(PIN_LED_RED, OUTPUT);
  pinMode(PIN_LED_GREEN, OUTPUT);
  pinMode(PIN_BUZZER, OUTPUT);

  Wire.begin(PIN_I2C_SDA, PIN_I2C_SCL);

  xTaskCreatePinnedToCore(
    SensorTaskCode, "SensorProcessingTask", 10000, NULL, 1, &SensorProcessingTask, 1
  );

  WiFi.mode(WIFI_STA);
  esp_now_init();
}

void loop() {
  uint8_t broadcastAddress[] = {0xFF, 0xFF, 0xFF, 0xFF, 0xFF, 0xFF};
  esp_now_send(broadcastAddress, (uint8_t *) &txData, sizeof(txData));
  delay(50); // 20Hz Telemetry Rate
}
