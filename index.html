1. EXECUTIVE SUMMARY & PARADIGM SHIFT

1.1 The TRISHUL Deterministic Solution

Standard low-cost hazard scouting prototypes (including legacy systems relying on simple Ultrasonic and Infrared sensors) suffer from a fundamental flaw: Acoustic and Spatial Ambiguity. Ultrasonic sensors emit wide, blurry cones that cannot detect diagonal hazards or narrow obstacles. This results in the software outputting only a statistical guess of obstacle presence.

Project TRISHUL replaces statistical estimation with a Hardware-Level Coincidence Engine and Swept Solid-State LiDAR. The breakthrough architecture involves hooking four VL53L1X high-precision Time-of-Flight (ToF) laser distance sensors to four separate MG90S metal-gear servos—one assembly per quadrant of the robot chassis.

Furthermore, TRISHUL verifies the physical possibility of a chemical hazard by enforcing a strict logical "AND" across independent physical domains: digital gas spectroscopy (SGP41, NH3), inductive metal sensing (LJ12A3), and thermal mapping (MLX90614). This allows TRISHUL to deliver military-grade reconnaissance capabilities for a fraction of commercial costs.

3. STEP-BY-STEP HARDWARE BUILD GUIDE

⚠️ Engineering Note on Vibration: Because TRISHUL is a tactical 4WD rover, standard DuPont jumper wires will rattle loose during terrain traversal. You must solder the Power Distribution Hub directly onto a perfboard. Only use jumpers for data lines to the ESP32-S3, and secure them with a dab of hot glue upon final verification.

Phase 1: Drivetrain & Master Power Hub

  • Step 1.1: Mount the four 12V BO motors to the corners of the chassis. Wire the two left motors in parallel to `OUT1/OUT2` on the L298N. Wire the two right motors in parallel to `OUT3/OUT4`.
  • Step 1.2: Mount the L298N driver centrally. Connect the LiPo battery's raw 11.1V line (via a master XT60 switch) directly to the L298N's `VMS / +12V` terminal. Connect L298N `GND` to the Common Ground Bus.
  • Step 1.3: Solder the LM2596 buck converter onto a 2x2 inch perfboard. Connect its `IN+` and `IN-` to the 11.1V LiPo switch output and Common Ground.
  • Step 1.4: CRITICAL: Using a multimeter, turn the LM2596's brass potentiometer screw until the `OUT+` terminal reads exactly 5.0V. This will power the ESP32-S3 `VIN` and all 4 MG90S Servos.

Phase 2: The LiDAR Swept Arrays (Quadrants)

  • Step 2.1: Mount one MG90S servo at each corner of the robot (Front-Left, Front-Right, Rear-Right, Rear-Left). Connect their power pins to the 5.0V rail from the LM2596.
  • Step 2.2: Attach a VL53L1X ToF sensor to each servo horn. Ensure the sensor points perfectly outward when the servo is at 45 degrees.
  • Step 2.3: Wire all four ToF `SDA` and `SCL` lines in parallel to ESP32 GPIO 8 and 9. Wire the 4 ToF `VCC` lines to the ESP32-S3 3.3V Pin.
  • Step 2.4: Wire the `XSHUT` pins of the four ToF sensors to separate ESP32-S3 GPIO pins (33, 34, 35, 36). This is mandatory to prevent I2C address collisions on boot.

Phase 3: Coincidence Sensor Payload

  • Step 3.1: Mount the LJ12A3-4-Z/BX facing downwards. Connect the Brown wire to 11.1V, Blue to GND, and Black (Signal) to ESP32 GPIO 6 (defined as INPUT_PULLUP in code).
  • Step 3.2: Mount the SGP41, MLX90614, and MPU6050 to the shared I2C bus (GPIO 8 and 9). Power them from the ESP32's 3.3V pin.
  • Step 3.3: Wire the DFRobot NH3 sensor Analog Out to ESP32 GPIO 4.

4. APPLIED MATHEMATICS: COORDINATE TRANSFORMATION

Each swept sensor assembly acquisitions data in Polar Coordinates $(r, \theta)$. The sensor returns a direct distance measurement ($r$) to the obstacle at a specific global sweep angle ($\theta_{\text{global}}$). The global angle must compensate for the robot's heading and the sensor's mounting offset on the chassis:

$$\theta_{\text{global}} = \theta_{\text{robot\_heading}} + \theta_{\text{quadrant\_offset}} + \theta_{\text{servo\_sweep}}$$

To build a flat obstacle map used for point-to-point navigation, the polar data points $(r, \theta)$ are transformed into Cartesian Coordinates $(x, y)$ relative to the robot's static center point $(0,0)$:

$$x = r \times \cos(\theta_{\text{global}})$$ $$y = r \times \sin(\theta_{\text{global}})$$

5. COMPLETE UNIFIED FIRMWARE (C++ / FREERTOS)

Below is the complete, unified main.cpp (or Sketch) for the ESP32-S3. It includes the FreeRTOS dual-core task pinning, I2C address reassignment for the ToF collision fix, synchronous servo sweeping, Cartesian mapping mathematics, the Chemical Coincidence Engine, and ESP-NOW telemetry broadcasting.

/* 
 * PROJECT TRISHUL - MASTER FIRMWARE 
 * Architecture: ESP32-S3 Dual-Core (FreeRTOS)
 * Payload: 4x VL53L1X LiDAR, LJ12A3, SGP41, NH3, MPU6050, MLX90614
 */

#include <Arduino.h>
#include <WiFi.h>
#include <esp_now.h>
#include <Wire.h>
#include <ESP32Servo.h>
#include <SparkFun_VL53L1X.h> 

// --- PIN DEFINITIONS ---
#define PIN_I2C_SDA 8
#define PIN_I2C_SCL 9

#define XSHUT_FL 33 // ToF Front-Left
#define XSHUT_FR 34 // ToF Front-Right
#define XSHUT_RR 35 // ToF Rear-Right
#define XSHUT_RL 36 // ToF Rear-Left

#define PIN_SRV_FL 15
#define PIN_SRV_FR 16
#define PIN_SRV_RR 17
#define PIN_SRV_RL 18

#define PIN_NH3_ADC 4
#define PIN_METAL_SENS 6
#define PIN_LED_RED 2
#define PIN_LED_GREEN 3

// --- GLOBAL OBJECTS ---
Servo servoFL, servoFR, servoRR, servoRL;
SFEVL53L1X tofFL(Wire, XSHUT_FL);
SFEVL53L1X tofFR(Wire, XSHUT_FR);
SFEVL53L1X tofRR(Wire, XSHUT_RR);
SFEVL53L1X tofRL(Wire, XSHUT_RL);

TaskHandle_t LidarScanTask;
uint8_t occupancyGrid[100][100]; // 10m x 10m at 10cm resolution

typedef struct __attribute__((packed)) {
  uint8_t threat_stage;    
  float nh3_ppm;           
  bool metal_present;      
} TelemetryPacket;

TelemetryPacket txData;
uint8_t remoteAddress[] = {0xFF, 0xFF, 0xFF, 0xFF, 0xFF, 0xFF};

// --- I2C TOF ADDRESS REASSIGNMENT ---
void initToFSensors() {
  pinMode(XSHUT_FL, OUTPUT); pinMode(XSHUT_FR, OUTPUT);
  pinMode(XSHUT_RR, OUTPUT); pinMode(XSHUT_RL, OUTPUT);

  digitalWrite(XSHUT_FL, LOW); digitalWrite(XSHUT_FR, LOW);
  digitalWrite(XSHUT_RR, LOW); digitalWrite(XSHUT_RL, LOW);
  delay(10);

  digitalWrite(XSHUT_FL, HIGH); delay(10);
  tofFL.begin(); tofFL.setI2CAddress(0x30); 

  digitalWrite(XSHUT_FR, HIGH); delay(10);
  tofFR.begin(); tofFR.setI2CAddress(0x31);

  digitalWrite(XSHUT_RR, HIGH); delay(10);
  tofRR.begin(); tofRR.setI2CAddress(0x32);

  digitalWrite(XSHUT_RL, HIGH); delay(10);
  tofRL.begin(); tofRL.setI2CAddress(0x33);
}

// --- CARTESIAN MATH ROUTINE ---
void mapPointToGrid(int distance_mm, float global_angle_deg) {
  if(distance_mm == 0 || distance_mm > 4000) return; 

  float r_cells = distance_mm / 100.0;
  float rad = global_angle_deg * (PI / 180.0);

  int x = 50 + (int)(r_cells * cos(rad));
  int y = 50 + (int)(r_cells * sin(rad));

  if(x >= 0 && x < 100 && y >= 0 && y < 100) {
    occupancyGrid[x][y] = 1; 
  }
}

// --- CORE 1: SYNCHRONOUS SWEEP & MAP ---
void ScanTaskCode(void * pvParameters) {
  for (;;) {
    ulTaskNotifyTake(pdTRUE, portMAX_DELAY); // Wait for trigger
    memset(occupancyGrid, 0, sizeof(occupancyGrid));

    const int SERVO_STEP = 2; 
    const int SETTLE_MS = 25; 

    for (int angle = 0; angle <= 90; angle += SERVO_STEP) {
      servoFL.write(angle); servoFR.write(angle);
      servoRR.write(angle); servoRL.write(angle);
      
      vTaskDelay(pdMS_TO_TICKS(SETTLE_MS));

      tofFL.startRanging(); tofFR.startRanging();
      tofRR.startRanging(); tofRL.startRanging();
      
      while(!tofFL.checkForDataReady() || !tofFR.checkForDataReady());
      
      int d1 = tofFL.getDistance(); int d2 = tofFR.getDistance();
      int d3 = tofRR.getDistance(); int d4 = tofRL.getDistance();
      
      tofFL.clearInterrupt(); tofFR.clearInterrupt();
      tofRR.clearInterrupt(); tofRL.clearInterrupt();

      mapPointToGrid(d1, angle + 45);        // FL Quadrant
      mapPointToGrid(d2, angle + 135);       // FR Quadrant
      mapPointToGrid(d3, angle + 225);       // RR Quadrant
      mapPointToGrid(d4, angle + 315);       // RL Quadrant
    }
    
    servoFL.write(0); servoFR.write(0);
    servoRR.write(0); servoRL.write(0);
    Serial.println("SCAN COMPLETE");
  }
}

// --- CORE 0: NETWORK & COINCIDENCE MATRIX ---
void setup() {
  Serial.begin(115200);
  Wire.begin(PIN_I2C_SDA, PIN_I2C_SCL);

  pinMode(PIN_METAL_SENS, INPUT_PULLUP);
  pinMode(PIN_LED_RED, OUTPUT);
  pinMode(PIN_LED_GREEN, OUTPUT);

  initToFSensors();
  
  servoFL.attach(PIN_SRV_FL); servoFR.attach(PIN_SRV_FR);
  servoRR.attach(PIN_SRV_RR); servoRL.attach(PIN_SRV_RL);

  xTaskCreatePinnedToCore(ScanTaskCode, "LidarScanTask", 10000, NULL, 1, &LidarScanTask, 1);

  WiFi.mode(WIFI_STA);
  esp_now_init();
}

void loop() {
  // 1. Run Deterministic Coincidence Logic
  float rawNH3 = analogRead(PIN_NH3_ADC);
  txData.nh3_ppm = (rawNH3 / 4095.0) * 300.0;
  bool chemAnomaly = (txData.nh3_ppm > 50.0);
  txData.metal_present = (digitalRead(PIN_METAL_SENS) == LOW);

  if (chemAnomaly && txData.metal_present) {
    txData.threat_stage = 3; 
    digitalWrite(PIN_LED_RED, HIGH); digitalWrite(PIN_LED_GREEN, LOW);
  } else {
    txData.threat_stage = 0; 
    digitalWrite(PIN_LED_RED, LOW); digitalWrite(PIN_LED_GREEN, HIGH);
  }

  // 2. Broadcast Telemetry 
  esp_now_send(remoteAddress, (uint8_t *) &txData, sizeof(txData));
  
  // Test Lidar Sweep every 10 seconds
  static unsigned long lastSweep = 0;
  if(millis() - lastSweep > 10000) {
    xTaskNotifyGive(LidarScanTask); 
    lastSweep = millis();
  }
  
  delay(100); 
}
